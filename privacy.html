プライバシーポリシー

最終更新日：2026年11月8日

1. 対象

「Health Secretary (personal)」は、開発者本人だけが使う個人用ツールです。本人以外のユーザーのデータは扱いません。

2. 取得するデータ

本人の許可を得たうえで、Google Health から次のデータを読み取り専用で取得します：活動・運動、体の測定値（体重・心拍など）、睡眠、栄養、プロフィール。また、本人の Google ドライブに、このツールが作成したファイル（健康ログ）だけを書き込みます。

3. 使い道

取得したデータは、本人向けの健康レポート・食事と運動の提案を作るためだけに使います。広告、販売、第三者への提供には一切使いません。

4. 保存場所

データは本人が管理するパソコンと、本人の Google ドライブにのみ保存します。

5. 削除

本人はいつでも Google アカウントの設定からこのツールのアクセス権を取り消せます。取り消した場合、ツールは新しいデータを取得できなくなり、保存済みのデータは本人の判断で削除します。

6. Google API サービスのユーザーデータに関するポリシーへの準拠

Google API から受け取った情報の使用は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
